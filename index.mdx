# Agentic Awesome Skills

AAS gives coding agents access to a broad library of reusable `SKILL.md` playbooks. **AAS Core** adds a local, read-only catalog interface and a reviewable workflow for composing exact skill sets before any installation change.

## Start with AAS Core

Codex or Claude inspects your project, searches and reads the complete local catalog, then chooses exact skill IDs. AAS validates the proposed stack; you review it before the CLI previews any changes.

1. [Configure the local MCP and follow the Core quick path](/docs/users/aas-core).
2. [Understand the difference between skills, AAS MCP, and other MCP tools](/docs/users/skills-vs-mcp-tools).
3. [Review a stack and continue to an explicit install preview](/docs/users/usage).

The local AAS MCP does not upload your repository, rank skills, install files, or apply a plan. **Selection belongs to your coding agent; changes remain under your control.**

## Choose a path

- **AAS Core:** complete local catalog search and inspection, agent-owned selection, manifest validation, and immutable plan preview.
- **Plugins and bundles:** focused distribution options for supported coding agents.
- **Direct installation:** a compatible path for tools without a native AAS Core adapter.

See [Getting started](/docs/users/getting-started) for an overview, or [browse the full skill catalog](https://aaskills.tech/).

## Help improve AAS

AAS is community-maintained. Read the [contribution guidelines](/docs/contributors/community-guidelines), then use the [skill template](/docs/contributors/skill-template) and [quality bar](/docs/contributors/quality-bar) when proposing a skill.
